Notes to the validators (paste as is):
-------------------------------------------------
Hello,

This is the first submission of Portfolio, a photo gallery extension.

- Requirements: phpBB 3.3.15+, PHP 7.2 to 8.4, GD (EXIF recommended, ZIP for
  exports and backups). Tested on MySQL/MariaDB (strict mode) and SQLite.
- Languages: English and French.
- The extension uses its own tables (phpbb_portfolio_*) and its own settings
  table; no core table is altered. Files are stored in files/portfolio/ and
  served only through a controller that checks permissions (.htaccess blocks
  direct access).
- Templates are Twig only; no jQuery, no external resources (inline SVG icons).
- A [portfolio] BBCode is installed on enable (and removed on purge).
- Notification types: comment, approved, mass_delete, rating, reaction, digest.
- Cron tasks: recycle-bin purge (disabled by default), export cleanup,
  notification digest, watermark cache cleanup.
- CLI commands: portfolio:backup, portfolio:restore, portfolio:migrate-gallery.
- Optional migration from phpBB Gallery (phpbbgallery/core): data is copied,
  phpBB Gallery tables are only read, never modified.
- The bundled font fonts/DejaVuSans-Bold.ttf (watermark) is free software;
  its license is in fonts/DejaVu-LICENSE.txt.

EPV result: 0 fatal, 0 error, 0 notice. The only warning is the bundled
TrueType font (fonts/DejaVuSans-Bold.ttf), reported as a binary file.

Thank you for your time.
verturin
-------------------------------------------------
